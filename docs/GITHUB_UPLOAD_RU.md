# Как показать CollabBoard и проверить GitHub

## Демонстрация вдвоём

1. Открой **Live demo** в README.
2. Введи своё отображаемое имя и нажми **Try the demo**.
3. Нажми **Invite people**, выбери Editor или Viewer и создай ссылку.
4. Скопируй её другу. На каждого человека нужна отдельная ссылка: она одноразовая и действует до часа.
5. Друг открывает ссылку, вводит имя и нажимает **Join the board**.
6. Создай карточку, перетащи её или добавь комментарий. Друг увидит изменение без обновления страницы.

Для проверки одному открой ссылку в режиме инкогнито или другом браузерном профиле. Обычная новая вкладка использует твою текущую сессию и не создаёт другого участника.

Owner управляет приглашениями и ролями. Editor меняет карточки и комментирует. Viewer только читает. В панели **People** владелец может поменять роль или удалить участника. Отзыв неиспользованной ссылки и удаление уже вошедшего человека — разные действия.

Если карточку одновременно редактируют два человека, вторая устаревшая правка не затирает первую. Нужно загрузить свежую версию кнопкой **Load latest** и внести изменения заново.

## Важно для демки

Доска доступна 24 часа с момента создания и очищается при перезапуске сервера. Это пространство для примеров, без постоянных аккаунтов и восстановления доступа. При потере сессии создай новую демку. Отображаемые имена не подтверждают реальную личность.

## Проверки на GitHub

Открой **Actions → Collaboration checks**. В запуске проверяются серверная логика, HTTP/SSE, сборка и браузерные сценарии с независимыми сессиями. Зелёный результат относится к конкретному коммиту. При ошибке браузерной проверки можно скачать `collaboration-browser-evidence`.

GitHub показывает код; **Live demo** открывает рабочий сервер. GitHub Pages не запускает этот Node.js/SQLite сервер и поток совместных обновлений.

## Загрузка из архива

Распакуй `CollabBoard`, создай пустой репозиторий и загрузи содержимое папки так, чтобы `package.json`, `Dockerfile` и `README.md` были в корне. Не забудь скрытую папку `.github/`. Не загружай `.env`, `node_modules`, `dist`, базы данных и результаты тестов.

```sh
git init -b main
git add .
git commit -m "Build CollabBoard collaborative Kanban workspace"
git remote add origin https://github.com/mileevskiyy/CollabBoard.git
git push -u origin main
```

В уже настроенном репозитории используй существующий `origin`. Адрес демки укажи в **About → Website**.

Для локального запуска нужны Node.js 24, `npm ci`, `npm run build` и `npm start`. Адрес — `http://127.0.0.1:3700`.
